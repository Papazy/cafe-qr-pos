ALUR SISTEM (SYSTEM FLOW)
Penjelasan terstruktur dari awal sampai akhir.

1. Flow dari Scan QR sampai Masuk Menu
Pelanggan scan QR Code.
QR berisi: https://website.com/order?table=5&token=xyz
Server memvalidasi token.
Sistem mengambil data meja.
Sistem menampilkan halaman menu digital.



2. Flow Pemesanan Menu
Pelanggan membuka daftar menu.
Pelanggan memilih item dan memasukkan ke keranjang.
Pelanggan menuju checkout.
Server memproses data keranjang.



3. Flow Checkout
Sistem meminta metode pembayaran.
Jika “Bayar di kasir”:
Sistem membuat pesanan dengan status Pending


Jika “Pembayaran digital”:
Sistem membuat pesanan dengan status Pending
Sistem mengarahkan ke payment gateway
Payment gateway mengirim callback setelah pembayaran
Status menjadi Paid




4. Flow Manajemen Order (Admin/Kasir)
Order baru masuk ke dashboard.
Admin melihat pesanan dengan detail:
nama meja
waktu
list menu
total


Admin mengubah status:
Pending → Paid → Complete
(Jika Customer sudah membayar, maka Paid)
(Jika Sudah dihidangkan maka Complete)
Sistem menyimpan aktivitas status.

5. Flow Laporan
Setiap order selesai → datanya masuk ke tabel transaksi.
Sistem melakukan agregasi otomatis:
total pendapatan per hari
jumlah pesanan
menu favorit


Admin membuka halaman laporan → grafik & tabel muncul.
